# GitHub User Activity CLI

A lightweight Command Line Interface (CLI) tool built with C# and .NET to fetch and display the recent activity of any GitHub user in real-time.

## 🚀 Quick Start
1. Clone this repository to your local machine.
2. Open your terminal in the project folder.
3. Run the application using the following command:
   ```bash
   dotnet run -- <username>
